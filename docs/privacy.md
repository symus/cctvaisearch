# Privacy, security and responsible use

CCTV AI Search processes CCTV footage and, from Milestone 4 onwards, biometric data: face and body embeddings derived from images of people.

## What the application does

- Everything runs on the local machine. There is no cloud inference, no telemetry, no remote analytics and no external image hosting.
- The server binds to `127.0.0.1` by default. Binding to another address logs a warning.
- Original recordings stay in place and are never modified. Deleting app data (`CCTV_DATA_DIR`) or an index never deletes footage.
- Reference photos, thumbnails, clips, embeddings and indexes are stored only under the data directory. Source control ignores that directory.
- The API only accepts filesystem paths for *scanning a folder*, and those paths are validated. Playback and other file access (later milestones) work by database ID and only within approved library folders.
- Browser protections:
  - a Host header allow-list blocks DNS rebinding;
  - cross-origin state-changing requests are rejected;
  - CORS is limited to the local UI;
  - the built UI is served with a CSP that forbids loading other origins.
- FFmpeg/ffprobe are run with argument lists, never through a shell.
- Logs never contain image contents or embeddings.

## What it does not do

- It does not identify people. It ranks *visually similar candidates* for a human to review. Similar clothing or appearance can belong to different people, and face similarity is affected by image quality, angle and lighting.
- It does not monitor covertly, alert automatically, or make automated decisions about anyone.

## Your responsibilities

Running locally does **not** in itself give you a lawful basis to process biometric data. Before using this software on real footage, make sure that:

- you have a lawful basis for processing biometric data (for example under the GDPR/UK GDPR Article 9, BIPA, or local law), and a data-protection impact assessment where one is required;
- the footage was lawfully recorded and you are authorised to search it;
- reference photos are obtained lawfully and kept only as long as needed;
- results are reviewed by a person before any action is taken, and the uncertainty is communicated;
- derived data (embeddings, thumbnails, search sessions) is deleted when no longer needed. Retention and deletion tools arrive with search in Milestone 6.

Test data shipped with or generated by this repository consists of synthetic test patterns and contains no people.
